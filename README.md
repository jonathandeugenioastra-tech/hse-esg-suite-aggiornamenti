# HSE & ESG Suite – aggiornamenti

Pacchetti di aggiornamento della HSE & ESG Suite (© 2026 dr. Jonathan D'Eugenio).

Il file `aggiornamenti.json` viene scaricato automaticamente dal programma quando si lavora in modalità online e aggiorna tutte le maschere interessate: valori limite, norme ed edizioni, banche dati, metodi. Lo stesso file si può importare a mano con «Importa aggiornamenti (file .json)», anche lavorando offline.

Il repository contiene solo i pacchetti di aggiornamento: non contiene il programma né dati di aziende o lavoratori.
